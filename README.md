## 本文の作り方

青空文庫のテキスト（入力: 大久保ゆう、校正: Juki）を底本とした。青空文庫の底本は『ふるさと文学館　第三三巻　【大阪Ⅱ】』（ぎょうせい、1995）。行分けは青空文庫のまま。

## ファイル

| パス | 中身 |
|---|---|
| `honbun/` | 本文。1 行が 1 段落で、`段落ID<TAB>本文` の形です。原本の行の切れ目は ⏎ で示しています（⏎ は改行の印で、本文の字ではありません）。50段落ごとにファイルを分けています（1ファイル）。 |
| `haru-no-shishu.json` | 本文・底本・作品の説明をまとめた JSON（訳は入れず、`yaku/` だけに置いています）。段落ごとに原本のコマ番号があります。振り仮名（`ruby`）もここにあります。 |

段落ID（例: `haru-no-shishu-000001`）は、本文を直しても変わりません。データの形は雲居の文庫の作品リポジトリと同じです。

## 誤りを見つけたら


- **Issue で知らせる**：[「本文の誤り」の Issue を作る](https://github.com/ginga-no-fumigura/haru-no-shishu/issues/new?template=teisei.yml)。段落ID・いまの本文・直した本文・根拠を書いてください。
- **直接直す**：`honbun/` の該当行を直して Pull Request を送ってください。段落IDと行の順番は変えないでください。

受け取った修正は、底本と照らして確かめてから取り込みます。
